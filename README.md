# GoWalk

## Назначение

GoWalk — сервис для создания и подбора пешеходных прогулочных маршрутов
по городу. Пользователь может создавать собственные маршруты, указывая
точки интереса, длину и сложность, а также просматривать и оценивать
маршруты, созданные другими пользователями.

## Целевая аудитория

Жители и гости города, которые хотят провести время на свежем воздухе:
любители пеших прогулок, туристы, семьи с детьми, люди, восстанавливающие
физическую форму после травм и ищущие маршруты подходящей сложности.

## Предметная область

Сервис планирования пеших прогулок в городской среде. Приложение хранит
маршруты, состоящие из точек интереса, с привязкой к пользователям,
которые эти маршруты создают, проходят и оценивают.

## Основные сущности

- Пользователь (User)
- Маршрут (Route)
- Точка маршрута / точка интереса (Waypoint)
- Отзыв о маршруте (Review)

## Основные функции

- регистрация и авторизация пользователей;
- создание и редактирование пешеходных маршрутов с указанием точек интереса;
- расчёт длины, продолжительности и уровня сложности маршрута;
- проверка погодных условий для комфортной прогулки по маршруту;
- поиск и фильтрация маршрутов (по длине, сложности, району города);
- оставление отзывов и оценок пройденных маршрутов.

## Возможности (ПР2)

Консольное приложение работает с набором маршрутов и отзывов,
данные сохраняются в JSON-файлах и загружаются при запуске.

- просмотр списка публичных маршрутов и карточки маршрута;
- поиск маршрутов по названию или точке интереса;
- подбор маршрутов по сложности, максимальной длине и району;
- сортировка маршрутов по названию, длине и сложности;
- добавление и удаление маршрутов;
- расчёт сложности и продолжительности прогулки;
- отзывы и оценки маршрутов, расчёт средней оценки;
- проверка погодных условий для прогулки.

## Структура проекта

- `main.py` — точка запуска, меню и вывод данных;
- `routes.py` — работа с маршрутами (добавление, поиск, отбор,
  сортировка, расчёт сложности и продолжительности);
- `reviews.py` — работа с отзывами и оценками;
- `weather.py` — проверка погодных условий;
- `storage.py` — сохранение и загрузка данных (JSON);
- `utils.py` — ввод данных с обработкой ошибок;
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты.

## Формат данных

`data/routes.json` — список маршрутов:

```json
{
    "id": 1,
    "name": "Прогулка по набережной",
    "district": "Хамовники",
    "length_km": 4.5,
    "elevation_gain_m": 60,
    "waypoints": ["Крымский мост", "Музеон"],
    "author": "Никита",
    "is_public": true,
    "created_at": "2026-09-14"
}
```

`data/reviews.json` — список отзывов:

```json
{
    "id": 1,
    "route_id": 1,
    "author": "Анна",
    "rating": 5,
    "text": "Красивые виды на реку.",
    "created_at": "2026-09-16"
}
```

Сложность и продолжительность маршрута не хранятся, а вычисляются
по длине и набору высоты.
